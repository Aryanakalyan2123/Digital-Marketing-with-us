GETINFO REACH WEBSITE
=====================

FILES
- home.html: Home page
- services.html: Services page
- about.html: About page
- pricing.html: Pricing page
- contact.html: Contact form
- booking.html: Appointment request form
- login.html / signup.html: Front-end account screens
- privacy.html / terms.html / cookies.html: Policy pages
- css/style.css: Shared premium styling
- js/script.js: Mobile menu and demo form interactions

HOW TO RUN
1. Extract the ZIP.
2. Open the GetInfoReach folder in VS Code.
3. Install/use the Live Server extension.
4. Right-click home.html and choose Open with Live Server.
5. Use the navigation links to move between separate pages.

IMPORTANT
- Forms currently show a demo success message. They do not send emails or save accounts.
- Login/signup need a secure backend and database before real use.
- Connect a real booking calendar/email service before accepting appointments.
- Replace hello@getinforeach.com with your real business email if needed.
- Pricing and policy pages are starter content. Confirm prices and have legal text reviewed before publishing.
